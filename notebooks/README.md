# Analytical Notebooks

The notebooks in this folder reproduce the main analytical pipeline used in the dissertation.

Run them in numerical order:

1. `01_data_exploration_and_preprocessing.ipynb` – data audit, cleaning and transfer-direction reconstruction.
2. `02_network_construction.ipynb` – construction of the directed weighted club network and network measures.
3. `03_louvain_clustering.ipynb` – Louvain community detection.
4. `04_node2vec_pca.ipynb` – Node2Vec embedding and two-dimensional PCA projection.
5. `05_interactive_visualisation.ipynb` – preparation of visualisation outputs used by the application.

The raw transfer dataset is not redistributed in this repository. See the main README and `data/README.md` for download instructions.
