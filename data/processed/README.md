# Processed Data

This folder contains processed analytical outputs generated by the notebooks and used in the dissertation and Streamlit application.

Included files:

- `cleaned_transfers.csv` – cleaned player-level transfer records.
- `club_edges.csv` – aggregated directed club-to-club transfer relationships.
- `club_embeddings.csv` – club-level network measures, Louvain assignments, Node2Vec embeddings and PCA coordinates.
- `club_nodes_with_clusters.csv` – club-level attributes and Louvain community assignments.
- `louvain_cluster_summary.csv` – summary statistics for the seven Louvain communities.
- `network_summary.csv` – summary statistics for the final transfer network.
- `top_countries_by_louvain_cluster.csv` – leading countries within each Louvain community.
